# QX Broker — gRPC requests

qx's data plane is **gRPC** — service `qx.v1.Broker` with **34 RPCs**
(the HTTP admin collection in `../` only covers the read-only dashboard/metrics
surface). Postman can call gRPC, but it consumes the **`.proto`**, not a
collection JSON — so this folder gives you everything to drive it.

## Files

| File | Use |
| --- | --- |
| `qx.proto` | Import into Postman (or pass to `grpcurl`). **No server reflection**, so this is required. |
| `qx.grpc_requests.json` | Example request message + metadata + streaming kind for every RPC — paste into Postman's message editor. |
| `qx-grpc.<stage>.postman_environment.json` | Importable envs: `grpc_url` + `qx_token`. |
| `qx.grpcurl.sh` | Runnable `grpcurl` cheat-sheet — works without Postman. |

## Postman setup (gRPC)

1. **New → gRPC Request.**
2. Server URL: `{{grpc_url}}` (import a stage environment below, or type `localhost:50051`).
3. **Service definition → Import a .proto file →** select `qx.proto`. Pick
   service `qx.v1.Broker` and a method.
4. **Message:** paste the example for that method from `qx.grpc_requests.json`
   (the `message` field). `bytes` fields (`key`, `payload`, `result`, `bytes`)
   are **base64** strings.
5. **Metadata:** add `authorization` = `Bearer {{qx_token}}`.
6. Click **Invoke**. For `ReceiveStream` (server-streaming) the stream pane stays
   open until you cancel.

## Auth

All RPCs require gRPC metadata `authorization: Bearer <token>` (keyx API key with admin|owner role, or a configured local token). Missing/invalid → UNAUTHENTICATED.

## Stages (gRPC targets — `host:port`)

| Stage | `grpc_url` |
| --- | --- |
| Local / Dev | `localhost:50051` |
| Integration | `grpc.integration.qx.vexarr.com:443` |
| Staging | `grpc.staging.qx.vexarr.com:443` |
| Production | `grpc.qx.vexarr.com:443` |

> Non-prod hostnames follow the `grpc.<env>.qx.vexarr.com` convention and are not
> confirmed deploy targets — qx is reached at its configured `server.addr` bind
> (default `0.0.0.0:50051`). For TLS endpoints use port `443` and drop
> `-plaintext` in grpcurl / disable "Use plaintext" in Postman.

## RPC groups

- **Topics & Messaging** (9): OpenTopic, Send, SendBatch, Receive, ReceiveStream, Ack, Nack, ExtendVisibility, Stats
- **Consumer Groups** (3): StreamFromGroup, CommitGroupOffset, GetGroupOffset
- **Group Coordinator** (4): JoinGroup, Heartbeat, LeaveGroup, StreamForMember
- **Workflow Tasks** (9): CreateRootTask, CreateChildTask, GetTask, ListChildren, MarkTaskRunning, CompleteTask, FailTask, CancelTask, CompleteTaskWithEmits
- **Schema Registry** (6): RegisterSchema, GetSchemaById, GetSchemaVersion, GetLatestSchema, ListSchemaVersions, ListSubjects
- **Triggers** (3): RegisterTrigger, UnregisterTrigger, ListTriggers

## grpcurl quick start

```bash
export QX_GRPC_ADDR=localhost:50051
export QX_TOKEN=qx_live_xxx
./qx.grpcurl.sh         # or copy individual commands
```

> Generated by `../../../postman/gen_qx_grpc.py`. Excluded by design: the Kafka
> wire protocol (use any Kafka client) and the internal Raft cluster RPCs.
